# Vault Breaker Preservation

Research toward preserving Marathon's Vault Breaker mode using a specific archived Marathon build and its original runtime where feasible. The first milestone is a reproducible, verified technical breakthrough; the mode is not yet known to be playable offline.

Start a new Codex chat in this folder and use [GOAL.md](GOAL.md). The goal directs Codex to use the reverse-engineer-anything skill and REA tools, investigate available artifacts, and document evidence.

- `research/` — findings, experiment records, and build provenance.
- `scripts/` and `tests/` — research tools and their checks.
- `GOAL.md` — the initial goal and operating boundaries.

Keep original game installations, archived game files, exports, large analysis databases, credentials, and copyrighted assets outside this repository. Record their paths and hashes in research notes as appropriate. This repository is local; no remote has been configured.
