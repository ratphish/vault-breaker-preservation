# Vault Breaker preservation: first goal

Create and pursue a persistent Goal for this project.

## Ultimate objective

Preserve Marathon's Vault Breaker PvE mode so it can eventually be experienced independently of the live service, using a specific preserved Marathon build and its original Tiger runtime wherever feasible. Preserve the environment, gameplay, vault interactions, encounters, and extraction loop as faithfully as possible; reconstruct missing components if necessary.

## Context

The user is separately reconstructing the Cryo Archive vault in Blender from a MIDA export. That work may provide references, but Blender and Unreal are outside this goal. Sunrise, Tigris, and community Destiny activity projects provide research leads, not proof of compatibility with Marathon. Vault Breaker has had multiple versions; establish which available files represent which version. Do not assume a complete build is already archived.

## Required tools

Read and use the reverse-engineer-anything skill and its REA tools where appropriate to investigate actual Marathon files and runtime behavior. Inspect relevant supporting resources, and use other tools when they answer a question better. REA does not automatically understand Marathon or recover server-side code: validate findings independently. If required tooling is unavailable, identify the missing dependency and continue independent work where possible.

## First goal: a verified breakthrough

Make and verify a concrete technical breakthrough toward running Vault Breaker in a preserved Marathon build. Leave reproducible evidence and tools that move the project toward an independently playable mode.

A breakthrough is a tested result that materially reduces a central unknown. Examples include tracing a verified Vault Breaker or Cryo activity reference through actual game data; a repeatable read-only tool that identifies relevant activity, entity, or vault data and is independently validated; a demonstrated local runtime capability relevant to Cryo; or a tested client/service boundary that changes feasibility.

A source summary, asset inventory alone, speculation, or plan is not a breakthrough. A negative result counts only if reproducible, it rules out a concrete proposed route, and it provides a specific evidence-backed alternative.

## Work approach

1. Inspect relevant local research, MIDA exports, and available Marathon installations or archives. Consult other Codex chats if accessible; identify missing context without assuming access.
2. Record build identifiers, file locations, inventories, and hashes as useful. Preserve originals and work on isolated copies.
3. Research Sunrise, MIDA, and relevant public Tiger research, preferring primary sources. Separate confirmed facts, observations, hypotheses, and unknowns.
4. Analyze real artifacts with REA and other appropriate tools. Test hypotheses, develop useful scripts, and pursue promising alternatives rather than stopping after a plan or literature review.
5. Investigate what is local and what depends on services, activity orchestration, or progression. Do not assume the division in advance.
6. Keep durable research notes with provenance, sources, commands, experiments, failures, results, hypotheses, and next steps. Make findings reproducible.
7. If Vault Breaker is playable, identify time-sensitive opportunities to document gameplay and archive an available build. Distinguish actions you can do from those requiring the user.
8. At the breakthrough, report evidence, reproduction steps, what it does and does not prove, and the next milestone.

## Boundaries

Use the user's available files for preservation research. Do not modify the live installation, connect experimental modifications to Bungie's live services, interfere with other players, or redistribute game files. Use isolated copies and local experiments. Do not delete or overwrite original assets or prior work. Respect applicable licenses. Do not claim the mode is playable until demonstrated.

If missing access, files, or another external condition blocks all meaningful progress, explain exactly what is missing and the smallest action needed to unblock it. Continue independent work where possible.

Create the Goal in this chat and begin. Continue until a breakthrough is verified or a genuine external blocker prevents further meaningful progress.
